# Casos de prueba de caja negra — Sistema Veterinaria Los Pinos

Metodología: caja negra clásica — se conoce la entrada y el resultado esperado documentado en los requisitos/comportamiento del sistema, sin mirar el código interno. Cada caso indica su **evidencia**: si se verificó en vivo contra producción (Railway + Vercel) durante esta sesión, o si está cubierto por la suite automatizada de pytest que corre en cada `git push` (ver [`.github/workflows/ci.yml`](../../.github/workflows/ci.yml)).

Sistema bajo prueba: backend `https://tesis-veterinaria-backend-production.up.railway.app` (Railway), frontend `https://tesis-veterinaria.vercel.app` (Vercel). Fecha de verificación: 2026-07-11.
